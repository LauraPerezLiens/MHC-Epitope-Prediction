# Logs

- `scaler_sequential_20261110.log`: closed log of the completed scaler calculation.
- `shuffled_pipeline_20261110.log`: closed log covering split generation, metadata, validation and the first scaler attempt.
- `shuffled_pipeline_20261110.pid`: historical PID record. It does not establish that the process is still active; verify before acting on a PID.
- `concatenation_20261110.log`: concatenation progress.

Future training `run.log` files are stored alongside their outputs in `results/`. Data-archiving logs remain in `data/used_data/` with the archives.
